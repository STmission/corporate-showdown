# 30 · 单人拾取武器原型

2026-10-05 · 根工程 0.6.0 / Cocos 0.3.0 / rules-0.6.0

## 范围与制作理由

用户明确要求拾取枪械、锤子和剪刀，本轮补齐单人剧情中的可玩武器链路。当前覆盖手枪、冲锋枪、步枪、狙击枪、霰弹枪、机关枪六个类别及两件近战工具；采用原创名字、模型部件和本项目平衡参数。未覆盖 CSGO 每一把具体枪、所有射击模式或其美术品质，不把六类原型写成用户整项需求完成。

已确认办公层布局不改，仅在西侧可达通道放置八个拾取点；茶水间咖啡和护盾保留，单人旧键盘/转椅/灭火器拾取被本轮武器替换。合作历史分支仍使用旧道具，保留回归。新规则版本要求客户端重新加载；旧规则客户端不能继续操作新规则房间。性别、职务和服装不改变武器参数或判定。

## 已实现

- F / 拾取按钮：靠近并面向物体后单次拾取；E 长按拾取兼容原交互。服务端检查距离、朝向、通路和状态，物件只能被拿一次。
- B / 切换武器：在已拾取的库存中循环，弹药和工具耐久保留；持续按住不会每帧切换。
- R / 装填：有限弹匣与备弹，按本项目配置耗时；切换、倒地或断线取消，不能产生免费弹药。死亡后不会继续装填。
- J / 攻击：半自动需要重新按下；自动武器持续射击但受射速与弹药限制。霰弹枪六条有确定种子的散布射线；锤子和剪刀按范围、冷却与有限耐久攻击。
- 服务端三维射线：先取共享镜头的中心目标，再从玩家眼部射出检查，避免第三人称镜头绕墙攻击。墙体和主要家具会挡弹；友好剧情 NPC 会挡住射线但不受伤害、不丢失线索。没有头部加伤或布娃娃伤害。
- 已接入中文弹药/装填 HUD、场景物件、第一人称武器、第三人称持物与弹道反馈；新增原创 shot/reload/empty PCM 音效，音量沿用动作通道。L 不投掷枪械；可投掷近战工具并从库存移除。
- 输入短按在服务端记录到下一次模拟更新，消费一次；取消动作的中性输入、隐藏/菜单、断线与恢复清除待执行动作，重放输入序列不能再次排队。短按覆盖由针对输入时序的回归测试确认；实际 Cocos UI 另发现构建器把 Set 展开错误转换为 concat(Set)，造成动作名全部未注册。客户端已改用 Array.from 明确转换，编译产物验证见下文。

## 源资产与边界

`prototype/shared/weapon-geometry.mjs` 是原创、米制、+X 枪口/+Y 向上的部件源。Web / Cocos 用相同部件定义表现，Cocos 按颜色合并网格，武器资源和网格由独立管理器释放。`assets/weapons/parts.json` 关联源指纹；`blender/build_weapons.py` 导出八份独立 `.blend` / `.glb`，加入圆角以便继续美术加工。`blender/validate_weapons.py` 实际重开每一份源资产和导入每一份 GLB，比较世界包围盒，核对比例/轴向/原点及源导出指纹。

八份重开与导入验证已通过；`weapon-library.png` 已实际查看。目前模型仍为基础部件造型：剪刀握柄、刀尖、枪械型号细节、职业握持动作、手指绑定、装填动画、后坐力、ADS、瞄准镜、枪械材质与 LOD 尚未完成。运行时使用部件几何，尚未接入这些 GLB 的圆角拓扑，不能写成游戏内已经采用导出美术资产。第三人称持物挂在身体前方，尚非正确手骨握持。

弹道家具高度使用文档化的近似值：普通桌 .85m、椅 1.15m、冰箱 2.05m、书架 2m、音响 1.55m、吊床 .7m；墙体沿用登记高度。需与完整模型逐件对照后形成正式射击碰撞，不把近似高度称为美术精确碰撞。无穿透、破坏玻璃、弹壳、枪口火焰或弹孔，尚无每枪差异化枪声。
