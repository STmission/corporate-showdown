# 05 · 3D 美术与体验规范

制作参考：2026-10-02 起统一采用 [Riot 公开实践参考与本项目基线](11-riot-production-baseline.md)。本文件已有规则和数值按该基线评审；未验证的条目仍为设计目标。
版本 v0.2 · 方向已修正，资产待验收 · 性能预算为起始值，须经目标机验证

## 1. 视觉方向

采用偏写实 3D 办公场景：成年人约七到八头身，正常身高、服装、手部及办公设备比例。参考 CSGO 的第一人称空间感，使用原创角色与资产；不复制其地图、模型或音效。当前程序化模型用于验证比例与视角，尚未达到正式写实资产品质。

空间叙事从局促工位到开阔出口，光线从室内冷白过渡到户外暖色。颜色用来表达交接目标、出口与危险，不依赖颜色作为唯一信息来源。

主要镜头为第一人称透视，眼高约 1.68 米，初始垂直 FOV 76 度；鼠标水平/垂直环视，WASD 前后移动与侧移。增加瞄准准星和独立双手/持物模型，隐藏本人的世界模型；近裁剪约 0.045 米。正式版本需验证墙边武器穿模、眩晕、移动端触控与 FOV 设置。

## 2. 资产清单与交付链

每项资产交付：源文件、导出文件、材质/贴图、骨架与动画、碰撞/导航定义、预览、版权来源、性能统计和资源 ID。只提供一张 AI 图片或一个无法编辑的渲染视频不算完成建模。

流程：概念稿 → 灰模 → 镜头内轮廓检查 → 建模/UV → 绑定 → 动画 → 引擎导入 → 双端真机验收。AI 可辅助概念和纹理探索，最终网格、骨骼、权利来源和游戏性能仍需检验。

资产状态：提案、制作中、待验收、已验收、废弃；每项有负责人、版本、依赖和预计交付日期。无明确权利来源的资源不能进入发布包。

## 3. 建模与贴图预算

以下是低档模式的初始资源预算，不是平台官方限制或 Riot 公布的预算：

- 玩家/变身：每个 LOD0 约 6,000—10,000 三角面，LOD1 降至约 50%；骨骼不超过 60；默认最多两个材质槽。
- 普通 NPC：约 3,000—6,000 三角面；复用骨架和动画；BOSS 默认控制在玩家预算量级，特例需测量。
- 小道具：约 100—800 三角面；主要互动物体约 1,000—2,000；碰撞优先简单几何体。
- 普通角色主贴图 1024，杂物 256—512；图集复用，禁止为远景小物体分配独立大贴图。
- 首关低档模式可见三角面目标不超过 250,000；Draw Call 目标不超过 120；包含角色、环境和特效，UI 另记录。
- 初始场上上限：四名玩家、十二名普通敌人、一名 BOSS；波次设计和特效按此压力场景测试。

导入统一 1 单位 = 1 米；角色原点在脚底，轴向与引擎约定一致；缩放应用完成。武器与道具指定握持点、命中参考点和投掷原点。美术网格不能直接充当复杂战斗碰撞体。

材质采用经两端验证的轻量方案；优先烘焙光照、简化高光、受控阴影。低档关闭重后处理、屏幕空间效果和复杂透明叠层。

## 4. 骨架与动画

职业共享人形基础骨架；变身优先复用，必要时单独绑定。标准动作：待机、移动、三段普攻、闪避、职业技能、拾取、持物、投掷、交接、受击、倒地、救援、撤离、变身开始/结束。

动画事件标明预警、有效命中与恢复区间，不能仅靠动画回调在客户端决定伤害。服务端动作时间驱动逻辑，客户端根据状态播放并做视觉补偿。

默认逻辑控制移动，动画适配速度；Root Motion 若使用仅作为客户端表现输入，不能使不同帧率或平台产生不同位移结果。脚滑、模型穿桌、投掷物从错误位置生成均属验收缺陷。

## 5. 特效与音频

攻击预警先于装饰特效：地面范围、方向、倒计时与出口必须在四人变身时仍清楚。低档模式同屏粒子起始预算 500，控制透明覆盖；超过预算先简化表现，不删除必要预警。

不得使用高频全屏闪光表达连续命中；提供屏幕震动强度、闪烁效果、音效和音乐开关。危险预警同时提供形状/图标与声音，不能只靠音频。

音频分组：命中、技能、BOSS预警、系统通知、环境、音乐、对白。同类音效限制并发，避免四人同时打击造成嘈杂。音频方向为马上下班的紧迫感：通风背景、脚步、碰撞、广播与倒计时节拍；节奏从约 108 BPM 逐步提高至 184 BPM，最后一分钟加入提示音。v0.5.1 已加入独立音量、危险提示降低背景声、广播和危险字幕、偏好保存及音效并发限制；返回大厅停止节拍和广播。语音合成依赖设备的中文声音可用性。自动化混音逻辑已验证，实际听感、触控字幕及平台音频仍待验收，见 [19 文档](19-audio-mixing.md)。

## 6. UI 与触控

横屏适配安全区域，支持按钮大小和位置调整。HUD显示生命、剩余时间、交接数量、出口方向、变身能量与队友状态；时间与当前目标优先级最高。

按钮建议在典型手机上有至少约 9 mm 的有效触控区域，最终以真机可用性测试验收；相邻按钮留足间隔。强制长按只用于明确的交接/救援，拾取和普通攻击不增加复杂手势。

首次提示：“交接两件事，然后去电梯”。正式目标与可选支线使用不同图标及文案。出口打开后发出一次明确通知和路径指示。

结算显示个人是否准点、团队是否通关、全员撤离情况、交接/救援表现和获得奖励。不显示“付钱就能挽回本次失败”等诱导弹窗。

## 7. 美术验收

MUST 完成比例/轴向/贴图/骨骼检查；无缺失引用；有源文件与权利记录；命中点匹配逻辑；四人压力场景下危险区可读；低档模式达标。

性能不达标时按序检查透明叠加、材质数量、阴影、动画开销、纹理与面数；依据分析工具调整，不只凭“低模看起来应该快”判断。
