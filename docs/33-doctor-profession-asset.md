# 33 · 职业服装独立资产：女医生样本

2026-10-05 · 根网页工程 0.6.3 · 资产试作 v0.1 · Cocos 仍为 0.3.1

## 改动理由与范围

用户要求生活职业 NPC 的穿着、对话与人物特征一致，并把角色作为可复用资产。原林医生使用女电商服装，职业辨识度不足。本轮制作白大褂、蓝绿色内搭、深色长裤、听诊器、胸袋与胸牌；调整皮肤粗糙度、深色发丝和刘海。继续保留海景楼层、六位 NPC 行为和剧情；没有修改碰撞、属性、性别规则或战斗裁决。

独立源和导出位于 `assets/characters/professions-v1/female_doctor.blend` 与同名 GLB。制作工具是 `blender/build_doctor_character.py`，源为原独立女电商模型，指纹确认原源文件未改变。沿用项目已核对的 MakeHuman／MPFB 图形许可与 suits01 服装来源，新增配件为原创简单几何。未使用用户参考视频的角色文件或 CS/GTA 提取模型，没有复刻演员脸部。

## 实现与兼容

- 米制约 1.68 m，53 骨骼、15 网格、8 个原动作；8 张图像内嵌。
- 新增六个配件网格绑定到原角色骨骼，按原大褂邻近顶点传递并归一化权重。
- GLB 的眼睛材质保留 BLEND，头发为 MASK，皮肤／衣服为 OPAQUE。
- 根网页通过表现资源选择器为 `doctor` 女 NPC 使用样本，原玩家四职务 × 两性别仍使用旧八套资产。新路由白名单提供 GLB，不允许任意路径读取。
- `/studio` 增加“查看女医生样本”，可切回原装扮；直接预览地址 `/studio?character=female_doctor`。
- 网络协议仍为 3，规则仍为 0.6.1，布局仍为 v0.8。服务器原职业、治疗和剧情线索规则不变。
- Cocos 没有同步此样本；旧完整场景中的展示人物也未替换。当前单份 GLB 约 12 MiB，尚无 LOD／共享纹理或设备预算结论。

## 验证方法与状态

`blender/validate_doctor_character.py` 已实际重新打开源工程，核对所有角色网格的骨骼修改器、真实骨骼权重和动作；实际重新导入导出的 GLB，核对 53 骨骼／15 网格、8 动作、内嵌图像和眼睛透明。Idle 第 1 帧、Walk 第 10 帧、Attack 第 7 帧均检验有限坐标、身高和配件躯干范围，并实际渲染。

网页工作台已实际显示样本、切回男程序员并再次显示医生；证据是 `artifacts/doctor-studio-browser.png` 与 JSON。代码与资产回归检验原八套组合、职业样本选择、源／导出指纹、配件 skin、全部动作和透明材质；HTTP 测试检查资源状态、MIME 和 GLB 头。`npm run check` 与完整 87 项 `npm test` 已通过，日志为 `artifacts/doctor-character-check.log` 和 `doctor-character-regression.log`。Blender 两个脚本也通过 Python 语法检查。实际单人网页进入办公室后，资源清单包含 `female_doctor`，第一／第三人称切换与退出到大厅通过，证据为 `doctor-game-browser.png` 和 JSON；该次游戏截图位于出生点，未验收场景内医生的近距离交流视角。
