# 29 · 单人荒诞职场剧情改版

2026-10-05 · 用户六项新需求生效；v0.6.0 / Cocos 0.3.0 开发中

## 制作方向与兼容

当前出品范围改为单人剧情动作探索，支持第一／第三人称随时切换。优先保留已确认海景办公层，扩展各职业人物、交流与线索、解压剧情和可拾取枪械／近战道具。此前第一人称多人下班闯关为历史实现；合作入口从当前用户界面撤下，底层合作与相应测试暂留作兼容回归，不作为本版内容开发或发行承诺。单人房间在服务端限制一名玩家。

此调整由用户明确要求，优先于旧多人产品描述。Riot 公开实践参考中的清晰信息、动作反制、可信判定、资源追踪与质量验证继续适用。没有改变已确认空间，镜头和服装不改变命中范围。

## 六项需求与落实状态

1. 双视角：默认肩后第三人称，V 与中文按钮切换第一人称。共享镜头算法对已登记墙体作带安全边距的三维线段裁剪；第一人称隐藏自己的身体，第三人称显示。暂未实现肩侧切换、瞄准缩放、近墙过渡、家具镜头碰撞或完善手臂。
2. 拾取道具：必须补齐手枪、冲锋枪、步枪、狙击枪、霰弹枪、机关枪与锤子、剪刀；拾取、切换、装填、弹药、命中与消耗由可信规则处理。枪械和新近战道具尚未实现，不把旧键盘/转椅写成完成。规划覆盖 CSGO 各枪种的游戏类别和表现；单独建立中文目录、原创建模、平衡表与枪声，不使用来源不明的原作提取模型。
3. 剧情：当前实现第一章“谁把假期改成了待办”的基础分支。老师给原始日程，律师给制度，财务给审批记录；集齐后选择协商或质询。探索不消耗倒计时；协商解锁离开，质询才开启原五分钟冲突。完整剧情、演出、后续章节、场景事件、破坏解压反馈仍未完成。
4. NPC：已写入老师、律师、医生、金融/财务、退役教官、诗人六位原创人物和中文对话。服务端验证距离、视线、话题、先决线索、连接/生命状态；线索和休息恢复不会重复发放，命令重试沿用幂等回执。现为编写的对话树与线索状态，非自由聊天大模型，未实现完整生活作息、巡游、敌我记忆或灵活行为。职业衣服暂为旧衣服占位，不能算通过职业形象验收。
5. 核心人物／场景资产：八套人物已拆成各自独立的可编辑 Blender 源工程，与原 GLB、骨骼、动作、贴图和指纹关联。此步骤保持旧外观，面部、头发、衣料、动作和表情仍需重做；不宣称达到参考视频品质。环境完整源工程保持不动，后续从分区集合导出模块、统一枢轴/米制/碰撞/材质，并检查重组一致性。
6. 中文与文化内容：本版用户界面和对话以中文为主，键位保持键盘实际字母。口头禅要符合职业、情绪和剧情用途；诗人台词为原创戏仿，避免人人机械说同一套梗。历史人物可开发独立原创形象；影视人物与在世艺人先做有原创姓名、脸部和台词的戏仿原型，具体直接角色和素材另做来源/授权核对。2026 热梗需要可核验来源及时间，当前原创对白不冒称年度热词；建立可替换文本包，尚无已验收的 2026 热词库。
