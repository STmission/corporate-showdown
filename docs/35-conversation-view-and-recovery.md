# 35 · 面对面交谈界面与操作恢复

2026-10-05 · 根网页 0.6.5 · Cocos 仍为 0.3.1

## 问题与改动

上一轮通用交流动作已经接入网页，但居中对白和大号世界提示牌挡住人物，交谈后按 Esc 的菜单状态也没有统一恢复。本轮将桌面对白移到右侧，窄屏使用底部面板，滚动区域与固定的“结束交谈”按钮分开。对白时暂时隐藏游戏操作 HUD、NPC 标签和任务提示牌；音频字幕保留并移开人物。

交谈镜头临时在玩家位置看向 NPC，隐藏自身模型和手部，保留原第一／第三人称选择、yaw 与 pitch。窄屏采用较低的取景目标，使对方脸部出现在底部面板上方。镜头只影响表现，不改变玩家位置、命中范围、输入方向或可信规则。结束后恢复原视角与方向，鼠标可再次拖动／点击场景操作。

实际近景复查还发现原表现代码把 `fz=0` 当作缺失值，正向横看时人物会偏转；改为保留合法零值，当前网页 NPC 面朝玩家。此修复不修改服务器朝向。

## 生命周期与兼容

`prototype/public/conversation-focus.mjs` 管理本地展示等待与服务器确认，不创建可信对话租期。发起请求后的未确认快照不会误关面板；确认后服务器取消／租期结束、人物失效、房间变化或玩家失去行动能力会恢复界面。请求超过 5 秒未确认会结束本地展示。断线、Esc、结束按钮和返回大厅也清理聚焦状态及输入。

打开对白前先设置菜单阻断，避免退出 pointer lock 的事件同时打开暂停菜单。只有服务器已有对话规则能发放线索、治疗或推进剧情，客户端退出命令仍经过原可靠序号。恢复函数统一处理标签、HUD、菜单和摄像机，避免关闭后残留。

办公楼、模型资产、协议 3、规则 0.6.1、布局 v0.8 保持不变。Cocos 尚未同步本轮交谈界面／镜头及朝向修正，未生成或验收新的引擎包。

## 已执行验证

- 本地状态测试覆盖等待确认、确认后释放、5 秒超时、缺 NPC、换房间、结束、倒地和断线；镜头覆盖各象限、重叠位置、非有限位置、俯仰限制及窄屏取景。
- 实际网页进入办公室，与许老师交谈并获得日程线索；NPC 正面、讲解动作和中文对白可同时看到。服务器租期结束后，面板自动关闭并恢复第三人称。
- 实际 Esc 关闭对白后，没有残留暂停菜单；结束按钮恢复原第一人称。进入／交谈／结束的第一／第三人称选择与角度一致，JSON 记录见 `artifacts/conversation-view-browser.json`。
- 原鼠标拖动方向为 yaw -0.3、pitch -0.099，交谈期间及结束后保持同值，证据 `conversation-drag-recovery.json`。本次 IAB 点击没有取得 pointer lock，不能把该测试写成已完成锁定鼠标状态验收；实际锁定后的恢复仍待检查。
- 实际 DOM 视口为 390 × 844，面板 352 × 371.36，结束按钮高 46、底边 819，均在屏幕内；长对白可滚动，脸部在面板上方。第一次尺寸设置对新标签未生效，检查实际 DOM 后重新设置并验证，不使用请求尺寸代替实际尺寸。
- 图像与尺寸证据为 `conversation-facing-desktop.png`、`conversation-facing-mobile.png` 和同名 mobile JSON。临时测试尺寸已重置，测试页已关闭。
- 最终 `npm run check` 与完整 93 项 `npm test` 通过，日志为 `artifacts/conversation-view-check.log`、`conversation-view-regression.log`。
