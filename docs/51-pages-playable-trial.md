# 51 · GitHub Pages 单人可玩试玩

2026-10-06 · 根网页 0.6.17 · 范围：公共单人浏览器试玩；完整双端目标继续。

## 变更理由与兼容影响

用户改为先发布网页供朋友试玩。GitHub Pages 不能执行 Node/WebSocket 服务，因此单独加入 LocalTrial + Worker 传输，复用现有模拟、命令幂等、事件确认、NPC、剧情、库存及碰撞。Worker 只用于 HTML 明确标记的静态试玩；正常 npm start 继续连接原 WebSocket。合作协议、服务器裁决、付费及在线权益边界保留。单人沙盒可被本机修改，不具有在线可信性，也不授予在线资产。

static-routes.mjs 统一 HTTP 与静态发行资源映射。build:pages 输出 dist/pages，改写绝对资源路径与原 public 层的 ../shared 导入，支持仓库子目录。只复制白名单路由及纯规则模块，不部署 Node 服务、Blender 源文件或本机凭据。源仓库保留可编辑资产和许可说明；忽略 Blender 自动备份、缓存、构建与日志。

## 可玩内容与限制

首章办公室、八种男女职务外观、职业 NPC 交流和日常活动、证据与分支、双视角、枪械／近战道具、射击及装填、菜单退出和重新进入。建议电脑 Chrome / Edge；触控入口已有，尚未代表手机性能验收。

无公开联机、账号云存档或真实支付。刷新页面重开；后台标签页可被浏览器暂停，不把 Worker 时钟视作可信在线时间。人物、动画和内容仍是制作中原型，微信／iOS 真机、签名和商店验收尚未完成。

## 验证与发布状态

本地 npm run check 通过，117 项完整回归通过。新增测试覆盖单人隔离、命令幂等、退出清理、仓库子路径导入和模型压缩。实际压缩人物用发行版 meshopt 0.22 解码，检查动画名称、骨骼路径、变形包围盒误差小于 6 mm；CPU 世界矩阵和第一人称手腕烘焙的采样坐标误差小于 1e-5。最终加载器变更另做针对性回归通过；这些是本地验证，不宣称 GitHub CI 或手机验收通过。

## 模型发行优化

静态白名单 86 文件，约 43.3 MB，原始发行资源约 296 MB。31 个 GLB 派生包应用 WebP 贴图和 meshopt；release.json 记录原文件及派生文件 SHA-256、大小、骨骼路径和动画名称。Blender 源文件与原始 GLB 保持不变。仅有动画的交谈资产保持原样，避免压缩清理误删其骨架。量化导出可能复制带不同逆绑定矩阵的 skin，校验采用完整祖先骨骼路径的唯一集合。

加载器在场景合批前将量化整数顶点属性恢复为 Float32，skinIndex 保留整数。这样 CPU 世界矩阵变换不会溢出量化位置范围，也不会因属性类型不一致造成合批失败。使用实际发行解码器验证，不只检查导出工具自身读取。

本地静态包已实际验证进入办公室、手枪拾取／射击、双视角切换、许老师日程线索、退出大厅及女生销售重新开局。压缩包与公网版本已实际进入办公室；公网验证手枪拾取、弹药 12/48→11/48、双向视角切换、许老师对话取得原始日程线索、菜单退出返回大厅。截图见 artifacts/pages-public-play.png。首次下载较慢，实际浏览器观察到场景与人物分阶段就绪；等待后正常进入，未发现加载错误。首次访问需下载人物与场景，网络较慢时应等待加载提示，失败可重试。
