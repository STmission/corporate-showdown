# 26 · 引擎音效素材制作

版本 v0.1 · 2026-10-04 · 原创声音素材已生成；引擎事件/混音/设置接入待完成

## 原因与实现

19 文档的 Web Audio 合成器不能直接作为微信/iOS 原生音频实现。本轮生成可追踪的 PCM WAV，供 Cocos AudioClip / AudioSource 后续使用，保留现有原型声音和已确认的下班节奏。没有改变规则、布局、人物或协议。

`platform/cocos/tools/generate_audio.py` 生成九个原创片段：脚步、命中、技能、危险警报、通知，以及 108/132/158/184 BPM 四种下班节拍循环。采用固定随机种子的噪声、扫频正弦和包络；没有采样第三方游戏/影视录音。每个循环包含四个等长拍，首尾零值，短音淡入/淡出。

产物位于 `platform/cocos/assets/resources/audio/`，22,050 Hz、单声道、16-bit PCM。`bank.json` 记录每个 WAV 的 SHA-256、帧数、采样率、峰值、生成器指纹和原创来源。仓库根目录 `npm run generate:cocos:audio` 可确定性重建；不是手工修改源 WAV 后仍沿用旧指纹。

## 已验证与未完成

新增实际文件测试在两个隔离目录重建：九片段逐字节相同，WAV 头、长度、指纹符合清单，首尾连续，无裁剪、非静音且直流偏移受限。全套 63 项测试通过，记录 `artifacts/cocos-audio-bank-regression.log`；根语法检查通过，生成器 Python 编译与新增测试单独复查通过。音频样本检查不等于耳机/扬声器听感验收。

目前素材尚未接入引擎播放。下一步接入原生 AudioSource 池、危险提示压低背景、快照阈值和蓄力去重、字幕、六项音量、偏好持久化及隐藏/退出清理；之后必须检查实际 Cocos 播放、微信/iOS 音频解锁和设备听感。不能把素材生成写成已经具备完整引擎音频。

后续 0.2.3 补充办公室环境循环，共十段，并接入引擎调度；最新状态见 [27 文档](27-engine-audio-integration.md)。本篇九段检查保留为历史记录。
