# 39 · Cocos 海岸天空与远景接入

2026-10-05 · 根工程 0.6.6 · Cocos 0.3.4

## 理由与兼容

透明度修复后，窗外灰色背景暴露了引擎缺少天空的问题。核对实际 GLB 发现海面、沙滩、棕榈树、沙滩家具与周边写字楼已经存在，并非需要另造一套室外布局。原 240 m 相机距离不足以涵盖宽 1,000 m、深 700 m 的海面。保留原完整场景与九区域模块，接入天空并把远距裁剪调至 900 m；近距保持原值。

不改变办公层、中央休息区、演讲／茶水间、电梯／卫浴、玻璃房间布局和碰撞，不改变单人剧情、NPC 行为与战斗规则。该修复让已确认的高层海边办公室在实际引擎可见，不能代表最终写实美术验收。

## 已实现

- `generate_coastal_sky.py` 生成六张 256 × 256 原创晴天立方体贴图，包含方向连续的蓝天、淡云与日光晕；不使用外部图片。RGB PNG、生成器与各面 SHA256、CC0 图形来源记录在 `platform/cocos/assets/resources/coastal-sky/`。
- `EngineCoastalSky.ts` 通过实际 Cocos ImageAsset 加载六面，生成 TextureCube，启用天空盒清屏。保留原环境光方案，关闭基于这张视觉贴图的 IBL，不把普通 RGB 日景图宣称为校准 HDR 光照。
- 相机改为 900 m 可见范围，天空失败时回退晴天底色并记录中文状态／错误；异步退出后不再安装资源，组件清理销毁自身天空纹理。玻璃透明修复继续生效。
- 构建门禁检查天空生成器与六张源图的指纹；新天空独立于 GLB 导入合同，原 11 模型／54 张 glTF 共享图像合同保持。

## 已验证

- `npm run check`、98 项完整回归、严格 Cocos TypeScript 检查通过。新增检查实际六面 PNG 的来源、尺寸、格式及所有相邻边的像素一致性；不是只核对意图或文件名。
- Web／微信构建（编辑器退出 36，经日志与导入／优化门禁确认）、11 模型／54 图像导入与 PNG 优化门禁通过。实际 Web／微信编译产物输入、职业选择和交流恢复检查通过。两端构建源码指纹均无漂移，微信设备运行未验证。
- 浏览器实际六面加载成功，天空 enabled、far=900、错误为空；单次出发进入场景、7 人物。由第三切第一人称，从 x=-18、z=5.8 沿通道前进到 z≈-19.5，进一步前进由窗边碰撞限制；俯视角约 -24°／-40° 实际看到源海面、沙滩与棕榈树。
- 玻璃 85 个环境渲染器保持修正；原实例化仍启用 5,898 个渲染器、61 个网格组、26 个材质组，失败 0。增加可见距离后的真实设备性能仍需测量。

证据为 `artifacts/cocos-coastal-sky-runtime-034.json`、`cocos-coastal-sky-034.png` 和 `cocos-coastal-sky-horizon-034.png`；检查／构建日志为 `cocos-coastal-sky-` 前缀。截图为实际桌面引擎浏览器，不是微信或 iOS 真机。

## 未完成与风险

海岸模型为静态表现，水面动画、真实反射、海平线过渡、沙滩／棕榈树最终材质和细节尚未完成；天空不是物理大气或动态天气。灰色天空缺失状态由此更新，不能把素材可见写成最终环境品质。相机扩大可见范围可能增加室外提交与深度精度压力，需设备帧时间／内存和近景遮挡测试；当前没有性能达标结论。

人物近景、职业完整服装、口型表情、武器握持、剧情全流程、首次加载优化、微信真机、iOS 本轮构建／签名、账户存档／权益与发行仍未完成。M0—M6 总目标继续执行。
