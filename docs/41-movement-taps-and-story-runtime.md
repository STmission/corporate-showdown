# 41 · 短按移动修复与协商路线实景验证

2026-10-05 · 根工程 0.6.8 · Cocos 0.3.6 · story-v0.3 · rules-0.6.2 · protocol 3

## 原因和兼容范围

短按方向键若在两次输入采样之间按下又松开，原先只读取 held 会丢失这次移动。修复本地意图采样，不改变服务器速度、伤害、碰撞和交互时长。保留已确认办公层、单人入口、男女／职务外观及旧合作底层回归。

## 已实现

InputControls 按来源记录尚未采样的方向按压；正常松开仍让该脉冲参与下一次采样，随后消费。已观察的长按松开立即停止，相反方向互相抵消；触控取消只取消自己的待处理方向，菜单／隐藏／失活清空全部。持续互动没有短按缓冲，不能借此跳过电梯的一秒交互。

根网页方向键使用同一个 InputControls；服务器新增明确的 JavaScript 模块路由。Cocos 同步共享实现，诊断 DOM 增加只读 story/result 数据，便于核对画面与权威结果。诊断不是剧情修改入口。

## 已验证

- `npm run check`、104 项完整测试、严格 Cocos 类型检查通过。新用例覆盖四方向一次消费、已观察长按释放、相反输入、镜头方向、多来源取消、模态清理及持续互动不延长。
- 首次完整回归中的旧网络结局测试失败，记录保留在 `artifacts/movement-tap-initial-regression.log`。该测试假定到达电梯后固定朝向；改为根据实际返回坐标持续朝向电梯，再单独跑真实网络流程和完整 104 项回归通过。未改变服务器距离／朝向门槛，也未延长超时。
- Web／微信构建成功，项目源码指纹均无漂移；实际编译产物的八种动作、方向脉冲、取消、分支锁定和个人结局验证通过。源模型／导出资产本轮未改。
- 实际 Cocos Web 场景原生键盘操作：三次短按右移后 x 从 -18 到 -17.54，正常继续走廊移动。实际依次获取老师原始日程、诗人宣言、律师公司制度、医生休息和财务审批记录，返回律师选择协商。服务器返回 `phase=resolved, route=reason`，画面显示最终文件／门禁卡完成、电梯开放。全程使用真实 UI 输入和只读 DOM 诊断，没有传送或修改剧情状态。随后通过行动菜单退出，实际返回大厅，诊断确认 status=home、actors=0、room 为空。
- 直线经过休息区会被已有家具碰撞阻挡；沿走廊可到达电梯。长距离自动键盘批次达到次数上限后，读取实际位置继续完成，不能把该工具次数上限写成移动故障。
