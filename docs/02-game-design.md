# 02 · 游戏设定与系统策划

制作参考：2026-10-02 起统一采用 [Riot 公开实践参考与本项目基线](11-riot-production-baseline.md)。本文件已有规则和数值按该基线评审；未验证的条目仍为设计目标。
版本 v0.1 · 待评审 · 数值为初始调参值

## 1. 世界观与叙事

虚构公司“无限待办集团”部署了自动效率系统 OVERWORK。它误把“员工仍在公司”理解为“效率提升”，开始把待办、会议和审批实体化，并封锁离开路线。

玩家已完成当天合理工作，需要完成最后交接，关闭失控系统的局部节点，从办公楼准点离开。老板、主管等 BOSS 采用正常成年人比例与偏写实服装，性格和招式夸张；友方同事可提供情报、开启近路或需要救援。

语气轻松、有反击感。败北是“错过下班，明天再来”，敌人退场采用眩晕、转椅滑走、纸片消散等动画。结尾展示街边夜风、公交站和自由时间，形成战斗后的情绪回落。

## 2. 核心循环

局外选关/角色/变身 → 建立房间 → 关卡简报 → 完成必要交接 → 应对阻拦与分支 → 破解 BOSS/出口机关 → 撤离 → 服务器结算 → 解锁和装扮。

局内不弹出商城、广告或长期养成界面。选择分支与拾取道具发生在移动和战斗过程中。

## 3. 时间与通关规则

### GDD-001 游戏时钟

首关剧情时间从 17:55:00 到 18:00:00，对应 300 秒活动时间；其他关配置 360—480 秒，对应各自起始剧情时间。剧情时间与实际倒计时 1:1 前进，与玩家所在时区或真实日期无关。

在线由服务器维护 `elapsed_active_ms` 和 `time_penalty_ms`：

`剩余时间 = 初始时长 - 活动耗时 - 时间惩罚`，最小为 0。

准备、资源加载、关卡简报不计时；全部参与者准备完成后服务器发出开始事件。在线菜单、切后台、掉线不暂停；单人离线练习可暂停，不能产生正式关卡奖励或排行记录。正式单人也采用权威房间。

迟到增援未准备完毕时不阻塞已开始房间；其准备时间预算与资源加载超时由房间服务控制。首发仅允许开局前加入和已有成员重连，局中陌生成员加入暂不开放。

### GDD-002 目标与出口

每关必须有 1—2 项必要交接，例如“提交最终文件”“取回自己的门禁卡”。它们是出口条件，不属于无限加班任务。额外审批、会议陷阱和支线宝箱属于阻拦或可选内容。

强制路径中的 BOSS 需满足其破局条件：击败、破坏控制器或特定交接解法，由关卡配置声明。只有标为可绕行的敌人允许直接避开；玩家不能通过越界穿墙绕过主线条件。

出口开启后，存活玩家进入出口圈并交互 1 秒，服务器确认后进入不可逆的 `Extracted` 状态。已撤离玩家无法返回战场；可观察与标记，不能攻击、救援或购买复活。

### GDD-003 多人结果

倒计时到 0 时先按服务器时间裁决已完成的撤离事件，再进入结算。至少一名玩家完成撤离即为团队通关；个人撤离奖励只给成功撤离者，未撤离成员保留小额参与奖励。全部成员撤离额外获得“全员准点”荣誉与普通软货币奖励。

时间结束或全员不可行动且无人已撤离则失败。部分玩家提前撤离时会显示“队友仍在公司”的提醒，不阻止自主撤离。不得因队友掉线扣除已获得的个人撤离资格。

结算由服务器单次生成，重连、重复请求和重放不能重复发奖。

### GDD-004 时间惩罚

普通受击只扣生命，不扣时间，避免双重惩罚。带“拖延”图标的特殊招式命中可扣 3 秒；同一玩家 5 秒内最多触发一次，全队单关累积上限初定 30 秒。命中展示“会议拖延 -3s”，提前预警，实际值由服务端配置。

没有付费加时。普通模式没有可无限刷取的加时道具；限时挑战可用独立规则，必须单独评审。

## 4. 战斗

### GDD-010 操作

第一人称鼠标环视与准星；WASD 前后移动/侧移；左键/J 普攻，空格闪避，K 职业技能，E 长按互动，L 投掷，Q 变身。移动端左摇杆移动，场景拖动环视，右侧触控按钮执行动作。普攻按瞄准方向判定，不自动转身击中背后敌人；近距离交互要求面向目标。ESC/右上菜单释放鼠标，继续行动或退出返回大厅，在线菜单不暂停服务器时钟。

普攻三段，第三段带击退；职业技能制造打断、控制或保护。拾取占用手持道具槽，普攻变为道具攻击，再按互动投掷；任务物品走独立任务槽，不因捡武器丢失。

### GDD-011 初始数值

玩家生命 100；三段普攻基础伤害 10/12/18；闪避距离 2.5 米、冷却 3 秒、无敌窗口 0.18 秒；职业技能冷却 8—12 秒；变身持续 12 秒。

普通近战预警 0.45 秒起，BOSS 大范围攻击预警 0.8 秒起。伤害在定义的命中帧结算，动画必须匹配逻辑判定。上述是原型起点，需经真机与延迟试玩调整。

命中反馈包含动作反应、短促音效、击退和局部特效。客户端表现顿帧不能暂停服务器时间或其他玩家模拟。控制效果设递减与 BOSS 免疫窗口，避免无限击晕。

### GDD-012 角色职业

- 研发“阿程”：部署短时干扰装置，打断机械敌人与机关；普通战斗同样可用。
- 设计“小绘”：墨迹区域降低敌人移动速度，方便绕行与队友救援。
- 运营“阿运”：短时鼓舞队友，提供有限护盾，不叠加无限增益。
- 行政“安安”：推车冲撞，清理狭窄通道；任务机关不绑定职业。

四种职业为横向玩法差异。切片先做阿程与安安。技能不能创造永久安全区，也不能封死其他玩家的出口。

## 5. 变身英雄

“下班意志”达到 100 激活；初始击中有效敌人 +3，成功打断 +8，完成交接 +15，救援 +15。重复打同一无敌目标、重复切换机关不产能量；全队共享交接事件的能量奖励按参与规则只发一次。

- 免费“闪退侠”：快速位移、冲击波、解除一次拖延控制。
- “纸翼游侠”：纸索牵引、短距离跨越、群体束缚；跨越只能落到验证的导航区域。
- “钢壳守护”：纸箱机甲、护盾和推开敌人，降低机动性作为代价。

角色、职业与变身分开：职业提供常规战斗，变身提供短时战术窗口。每人每局装备一种变身；收费英雄采用相近强度预算，有至少一种免费解法应对全部主线机制。

付费英雄提供新动作和策略。禁止“必须买某英雄才能开门”；付费内容只能在局外选择，进入房间后冻结该局战斗配置。

## 6. 倒地、救援与掉线

生命为 0 进入倒地 20 秒，期间不能攻击；队友在附近交互 3 秒救起至 40 生命，受击会中断。每人每关至多被救起两次，次数耗尽或倒地超时进入淘汰观察。单人普通模式提供一次免费自救，倒地期间可交互 3 秒恢复，不能暂停倒计时。

掉线角色保留原位置，不能因此获得无敌；短时保留身份 60 秒，允许同一账号重连。掉线不生成接管 AI，不开放位置替换；角色仍会受击。超过重连保留期进入离队状态；已完成撤离者保留结算资格。重连通过状态快照恢复，不能重复获得道具。

## 7. 多人规则

主线关闭队友伤害；投掷物可以推开敌人，不能把队友推出地图。关键任务物品共享进度，拾取分配采用服务器先到先得，重复请求返回原结果。

敌人生成按波次记录活跃人数；已生成敌人的生命和伤害不随掉线变化。下一波使用当前人数的配置，避免退出瞬间降低 BOSS 血量。初始普通敌人生命系数 `1 + 0.35 × (人数 - 1)`，生成数量通过表配置；BOSS 使用独立系数，伤害不按人数增加。

关卡从公共集合点进入，不使用强制将全队传送到领跑者身边的规则。联机标记提供“来这里”“救援”“开门”三种预设交流，首发不加入自由语音。

## 8. 成长与商业化

局外以职业熟练度、装扮、关卡解锁和横向技能选项为主。不会永久叠加攻击力导致老玩家碾压新玩家。

可以直购英雄、服装、道具外观与表情；收费英雄提供清楚的技能预览和训练试用。所有核心战斗道具在关卡中免费出现。

保留“付费得道具”的设想作为可选实验：局外直购开局工具包，只有合作普通模式可装备，最多一个道具槽；相同工具可通过游玩获得。不能作用于必要任务、计时器或正式竞技，进入局后不弹出购买。切片和首发默认不启用工具包收费，需验证平衡和平台支付可行性后评审。

首发不做付费随机抽取、不售卖撤离资格、不在失败时强迫付费复活。广告若后续启用，仅放在局外可选奖励入口，不能中断在线战斗。

## 9. 竞技扩展

后续“下班擂台”采用独立地图、统一数值、固定时间和独立结算；英雄从该模式提供的公共池选择，不受购买状态影响。合作撤离成绩与竞技排名不混用。

## 10. 优先验证的体验问题

倒计时是否造成持续焦虑；玩家是否理解必需交接与额外待办的区别；能否在 30 秒内找到出口方向；手机上是否容易误触变身；提前撤离是否破坏队友关系。首关试玩必须记录这些问题，不仅看胜率。
