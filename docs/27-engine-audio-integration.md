# 27 · Cocos 音频调度、设置与字幕

版本 v0.1 · 2026-10-04 · Cocos 0.2.3；Web/微信构建和浏览器播放状态复查完成；听感/真机未验收

## 实现与兼容

将 26 文档的九段素材补充一段办公室环境循环，共十个原创 PCM WAV。`AudioCues` 从权威快照和可靠事件生成表现提示：四档倒计时节拍、最紧迫阈值文字、14 米内未过期蓄力去重、受击和限频脚步、攻击/技能。退出和换房清理调度状态，不改变判定、协议或场景。

`EngineAudio` 使用 Cocos AudioClip / AudioSource，音乐和环境各独立循环源，短音十二槽池，效果同频道上限八、其他上限四，并设置触发间隔。危险/通知暂时将背景降至 22%；字幕危险优先，静音可保留字幕。隐藏停止声音，显示后按当前快照恢复；离开/销毁停止并释放自持有资源。

六项音量、静音和字幕通过中文声音设置面板控制；调用共享设置规范化及 sys.localStorage，受限/损坏存储回退默认。行动中打开面板清除输入并打开菜单，在线计时继续；返回面板后需继续行动。已清除主动退出后的旧通知，但其他状态提示残留仍需实际复查。

目前“广播提示音”是通知音配文字字幕，没有录制/合成语音。环境循环不是声学模拟；音效没有方位或墙体遮挡。资源就绪加入房间准备流程，失败可重试。构建验证生成器和每个 WAV 指纹，源码漂移需重新生成；本地服务补充 WAV MIME。

## 验证状态

## 实际浏览器复查

通过原生界面点击声音设置，总音量从 80% 调至 70%，再恢复原始 80%，读出的规范化设置对应变化；未改动其他偏好。单人出发加载十个 AudioClip，运行诊断显示 musicPlaying 与 ambientPlaying 为 true，并出现招式预警字幕；采集时浏览器错误/警告列表为空。通过菜单主动退出后，首页正常显示、旧通知清除，下一次诊断刷新显示 active=false、两循环 playing=false、短音数量 0、字幕空。诊断是引擎播放状态证据，没有确认扬声器实际声音或混音听感，也没有完成通关。

保存 `artifacts/cocos-audio-settings.png`、`cocos-audio-playing.json` / `.png` 和 `cocos-audio-stopped.json`、`cocos-audio-home.png`。退出点击后公共诊断最长等待下一次刷新才更新，首次立即读取仍可能是旧状态，不能当作未停止结论。

本地实际生成 WAV 路径 HEAD 返回 200 / audio/wav。65 项回归早于此 MIME 修改完成；后续运行语法检查与实际 HTTP 检查，未把旧测试报告写成覆盖新增 MIME 行。隐藏恢复、池上限、资源释放的真实引擎行为仍需专门复查。首页设置标题仍显示“在线计时继续”，属于待改的状态文案，不影响大厅计时规则。
