# 50 · 网页第一人称真实前臂接入

2026-10-06 · 根工程 0.6.14；Cocos 保持 0.3.11

## 理由与兼容范围

原网页第一人称使用几何手部，不能呈现独立人物资产的真实衣袖与蒙皮。接入 first-person-v1 十套前臂模板，以 SkeletonUtils 克隆独立骨架，播放既有动作，武器挂在真实 hand_r 骨骼。只为当前玩家准备前臂；NPC 仍加载完整人物。服装和性别不改变服务器判定、规则或办公层布局。

初始 PistolHold 混合完成后，按真实右腕位置把手臂适配到摄像机局部 (0.13, -0.28, -0.50) 米，不改变骨骼比例。Blender 重导入后的手骨局部轴向与原挂点不同，首次实景看到枪口朝上；在参考持握姿势校准固定挂点基变换，使枪身 +X 指向摄像机前方、+Y 保持相机上方。后续射击骨骼转动继续生效，并非每帧强行把枪转回固定朝向。

第一人称显示专用前臂，并隐藏旧几何手与对应旧武器；第三人称、交谈、主页及大厅隐藏专用前臂。换装或退出时停止动作、解除武器、移除相机节点并释放克隆骨架的 boneTexture，缓存模板几何／材质留作再次进入使用。未知旧道具保留原几何表现。

## 验证方法与记录

first-person-runtime.test.mjs 真正解析十套 GLB 的几何、蒙皮、骨骼与动作，分别验证男女外观的腕部相机位置、独立骨架、枪口／上方向、持握／射击选择、换武器、隐藏、退出及骨架纹理释放。该 Node 测试删除图片材质以避免浏览器图像 API，不能作为贴图品质验收。session-story.test.mjs 通过真实 HTTP 服务验证模块 MIME 与男女前臂资源，防止新增模块缺少路由。首次网页加载发现遗漏模块路由，修复后重启服务并重新进入验证。

浏览器实际男程序员和女生销售分别进入、切换第一人称、拾取手枪并显示相应衣袖；男程序员射击弹药 12 → 11，切回第三人称诊断为专用前臂 visible=false。两次退出后 firstPersonArms=null、weaponAttachments=[]，回到已连接主页。证据为 artifacts/first-person-runtime-{male,female}.png／.json 与对应 -exit.json。扣弹证明服务器处理射击；短暂射击动画的实际画面尚未单独捕获。

最终 npm run check 通过，npm test 的113项完整回归通过（73.393秒）。新增运行时蒙皮检查及 HTTP 路由检查分别通过，最后增加的只读诊断字段另经语法检查。语法与完整回归见 artifacts/first-person-runtime-check.log／first-person-runtime-regression.log；独立蒙皮运行时检查及 HTTP 路由检查见 focused／route 日志。
