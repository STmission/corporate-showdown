# 28 · Cocos 输入发送与界面生命周期

版本 v0.1 · 2026-10-04 · Cocos 0.2.4；完整构建与界面复查进行中

## 问题与修改

此前输入和会话重试在 `Component.update` 内，低画面帧率同时降低网络输入频率。服务器在 0.3 秒没有新输入时清空意图，因而客户端低于约 3.3 FPS 时会间歇停止移动。声音设置的 ESC 仅翻转菜单，可能留下设置面板却恢复移动判定。

输入/会话轮询改为独立 30 Hz 定时器，渲染只更新画面。共享 `InputControls` 根据镜头方向生成归一化移动和操作意图，支持键盘与触控同一动作独立释放；攻击、技能、闪避、投掷、变身的短按保留到下一次发送，互动仍按真实按住时长。触控取消清除未发短按。没有添加客户端战斗判定、修改数值或放宽服务端超时。

菜单、声音设置、隐藏和断线禁用并清空输入。进入菜单/设置和隐藏时立即发送一次中立意图；隐藏期间不再周期发送输入。显示/重连后须重新按下操作，防止旧按键残留。ESC 先返回声音面板外，行动中仍保留暂停菜单；连续 KEY_DOWN 不会因自动重复切换菜单。大厅声音标题移除无关的在线计时文字。销毁组件清理定时器。

定时器独立于渲染回调，并不保证主线程阻塞时仍能发送；浏览器后台节流、引擎线程阻塞和真机生命周期仍要实测。服务器继续固定裁决与超时保护，客户端不追赶发送堆积历史输入。此修改不代表帧率达标。

## 验证与状态

两项输入单元测试覆盖短按、持续按住、模态清理、取消、键盘与触控共存、归一化、镜头旋转、对向和非法操作。实际四客户端服务器集成测试保留四种外观、权威移动和重连，并新增无渲染回调的 600 ms 输入心跳与模态中立停止验证。

专项四项、完整 67 项回归、根语法和严格类型检查通过。Web/微信构建和实际中文界面仍在本轮复查，结果完成后追加，未把测试层意图验证写成真实手机输入验收。证据文件前缀 `artifacts/cocos-input-*`。
