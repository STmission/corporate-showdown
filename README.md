## 本地试玩

```sh
npm ci
npm start
```

打开 `http://127.0.0.1:4173`。当前单人入口默认第三人称，V 切换第一人称；鼠标环视，WASD 移动／侧移，T 交谈，F 拾取，B 切换武器，R 装填，左键／J 攻击，K 技能，空格闪避，E 长按交接／撤离，L 投掷，Q 变身，ESC／菜单返回大厅。旧多人底层仅保留兼容回归；正式平台适配和发布另行验收。

执行 `npm test` 验证玩法规则与网络流程，`npm run check` 检查源码语法；`npm run audit:assets` 生成源模型与导出资源的指纹报告。

## 文档治理

采用大厂项目常见的“立项—系统设计—技术预研—垂直切片—内容生产—测试发布”结构。2026-10-02 起以 Riot Games 公开工程实践和设计原则为制作参考。执行规范由本项目制定，不代表 Riot 内部标准或认证；详见 [制作基线与后续任务大纲](docs/11-riot-production-baseline.md)。

规范关键词：MUST 表示必须满足；SHOULD 表示默认遵循，偏离需记录原因；MAY 表示可选。v0.1 中的设计均可在评审后调整；进入对应里程碑后，MUST 条款作为验收门槛。

每份文档需维护版本、状态、负责人、评审人及变更记录。当前负责人和评审人待团队组建后分配；不得填造姓名。功能需求使用 `PRD-`，游戏规则使用 `GDD-`，关卡使用 `LV-`，技术使用 `TECH-`，测试使用 `QA-` 编号，以便追踪。

目前使用 Blender 场景、CC0 人体基础资产、原创造型与本地服务器；新增 GitHub Pages 单人试玩发布流程；尚未部署公网权威服务或接入真实收费。
